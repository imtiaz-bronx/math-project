## 📖 Overview
This project explores and visualizes **NYC Open Data** focusing on Yellow Cab taxi rides over a three-day period (March 1–3, 2023). Through data science techniques, this study aims to uncover patterns in urban mobility, fare structures, and trip distributions within New York City.

## 📊 Data Source
The dataset is sourced from the **NYC Open Data** portal, focusing on high-resolution trip records. 
* **Timeframe:** March 1, 2023 – March 3, 2023.
* **Key Metrics:** Trip distance, fare amounts, pick-up/drop-off locations, and passenger counts.

## 🛠️ Built With
This project utilizes a mix of web development and data analysis tools:
* **Frontend:** HTML5, CSS3 (Custom animations and layouts)
* **Analysis:** Python (Pandas for cleaning, Matplotlib/Seaborn for visualization, Sklearn for Modeling)
* **Hosting:** GitHub Pages

## 🚀 Key Insights & Visualizations
* **Trend Analysis:** Fluctuations in taxi demand over the 72-hour window.
* **Statistical Correlations:** Analyzing the relationship between trip duration and total fare.
